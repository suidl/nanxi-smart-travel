# “楠溪智游”项目简介（在线 MVP）

## 项目名称

楠溪智游——楠溪江动态行程决策智能体

## 参赛方向

赛道一“人工智能体（AI Agent）”——命题二“AI Agent × 永嘉特色产业”——文旅智能导览方向。

## 一句话介绍

输入同行人、预算、偏好和体力约束，楠溪智游会自主调用天气、景点、路线、预算和规则校验工具，生成可执行的楠溪江行程，并在下雨、闭园、拥堵或体力变化时只重排剩余安排。

## 用户痛点

楠溪江景点分散、山水与古村类型多，家庭游客往往需要同时处理交通距离、开放时间、天气、老人儿童体力和总预算。普通旅游问答只能“给建议”，难以保证行程时间不冲突、预算不超支，也不能处理途中变化。

## 解决方案

楠溪智游把旅行需求转成结构化约束，依次执行 6 个可见步骤：理解约束、查询天气、筛选景点、优化路线、核算预算、检查可执行性。结果以“行程驾驶舱”呈现，包含路线示意、逐站时间轴、费用拆分、数据来源和 Agent 工具轨迹。若触发午后阵雨，系统保留已完成节点，只替换后续不适合雨天的节点，并同步更新路线与预算。

## 核心创新

1. 从“旅游问答”升级为“可执行决策闭环”，所有结果经过预算、天气、开放时间和人群适配校验。
2. 用局部重排处理途中变化，不推翻整条行程，符合真实旅行场景。
3. Agent 执行轨迹可见，展示工具名称、输入摘要、耗时和结果证据，避免黑箱式推荐。
4. 公开数据均保留来源，不确定信息明确提示复核，演示数据与实时数据严格区分。

## 永嘉价值

项目以楠溪江山水、古村和地方文化点位为内容基础，帮助游客从单点打卡转向多节点串联，提升停留时长和文旅消费转化。后续可为景区、民宿、乡村运营方提供合规的内容接入和路线运营工具，但首版不依赖任何企业私有数据。

## 当前成果

- React + TypeScript 可运行 Web MVP；
- 27 条带来源的永嘉点位数据；
- 6 步 Agent 工具编排与执行轨迹；
- 午后阵雨等 5 类动态重排入口；
- PDF、ICS 日历和分享文案导出；
- 脱敏云端分享链接和本地自动保存；
- Open-Meteo 实时天气代理与缓存容错；
- OpenAI 结构化约束解析接口与本地规则降级；
- 33 条单元/组件测试、2 条本地浏览器流程和 1 条公网浏览器流程；
- 已发布公网体验版：https://nanxi-smart-travel.netlify.app 。

## 商业化设想

面向游客提供免费基础规划，面向景区、文旅集团和乡村运营方提供 SaaS 路线运营、内容管理、客流分流和数据分析服务。所有商业推荐必须明确标识，不能影响行程安全与可信校验。

## 当前边界

路线仍为坐标估算，不提供真实支付、预订或实时路况。实时天气不可用时会明确回退为演示数据；AI Gateway 不可用时，线上约束解析会明确回退为本地规则，不把规则结果伪装成模型结果。
